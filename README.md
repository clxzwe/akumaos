# AkumaOS

![AkumaOS Banner](assets/previews/banner.png)

AkumaOS is an open-source Linux desktop environment built for performance, aesthetics, and modern workflow efficiency.

> **Note:** AkumaOS is currently in early scaffolding and development. Features and configurations are actively being planned and structured.

---

## Features (Planned)

- [ ] Custom Hyprland compositor configuration
- [ ] Waybar status bar setup
- [ ] Ghostty terminal styling
- [ ] Hyprlock & Hypridle integration
- [ ] Wofi launcher configuration
- [ ] Mako notification daemon styling
- [ ] SwayOSD volume and brightness display
- [ ] Modular theme & wallpaper switching
