# Component Templates (`generator/templates/`)

## Purpose
This directory is reserved for application configuration templates (Hyprland, Waybar, Ghostty, Hyprlock, Hypridle, Wofi, Mako).

## Planned Component Responsibilities
- **Hyprland Templates**: Compositor config templates (`hyprland.conf.template`) containing placeholder variables for window rules, keybindings, and color tokens.
- **Waybar Templates**: Bar layout (`config.jsonc.template`) and CSS stylesheet templates (`style.css.template`).
- **Ghostty Templates**: Terminal configuration templates (`config.template`).
- **Hyprlock & Hypridle Templates**: Lock screen (`hyprlock.conf.template`) and idle daemon templates (`hypridle.conf.template`).
- **Wofi & Mako Templates**: Launcher and notification daemon layout/CSS templates.
